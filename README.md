## 原生 IP、家宽 IP、双 ISP，差在哪

**原生 IP** 指 IP 的注册归属地和服务器实际所在国家一致。悉尼机房分配一个澳洲注册的 IP，叫原生；分配一个美国注册的 IP，叫广播。TikTok 的风控系统对广播 IP 特别敏感，因为它意味着这台机器在“假装”自己不在的地方。

**家宽 IP** 比原生更进一步。它的 AS 号和注册信息来自当地 ISP 的家庭宽带段，扫出来就是一个普通住户。原生只保证“国家对得上”，家宽保证“身份像个人”。

**双 ISP** 是同一个 IP 同时在两个 ISP 名下注册，网络稳定性和信任度都比单 ISP 高一层。WePC 的洛杉矶、纽约、韩国、马来西亚、日本部分型号都提供双 ISP 版本。

选机房 IP 容易出问题的原因很直接：TikTok 扫一下 ASN 就知道这是商用出口，直接打上可疑标签。这个 IP 再被多个账号共享过，甚至有人拿它做过违规操作，你接上去就是一条被污染过的水管，冲多少遍流出来的还是浑水。新号 0 播放、老号突然掉流、直播中途被踢，多数栽在这一层。

业内配置原则叫“一机一号一IP”：一个账号对应一台独立设备或独立环境，绑一个固定不变的专属 IP，三者之间不交叉。做到这点，平台才把你当干净账号。

WePC 的套餐页会明确写“原生 IPv4”还是“原生家宽 IPv4”，下单前看清楚这一行，别只看价格。

## 常见问题

**原生 IP 和家宽 IP 哪个更重要？**
原生是底线，家宽是加分。IP 归属地和服务器所在国都不一致，家宽无从谈起。两个都满足最好，只能选一个时，优先保证原生，再看 AS 号是不是住宅段。

**买澳洲节点做美区账号行不行？**
不建议。账号定位、内容语言、发布习惯都指向美国，IP 却落在澳洲，风控那边的关联信号会更强。做哪个市场就买哪个地区的 IP，这是最省事的做法。

**退款具体怎么算？**
3 天内且流量不超 10GB，全额退余额，或扣 10 元手续费原路退。超出任一条件，按已用部分比例扣款后退余额，余额不能提现。买之前把这条看清楚，比事后扯皮有用。

**一台机器能挂几个号？**
业内的做法是一机一号一IP。一台机器绑一个固定 IP 对应一个账号，多账号共用一台机器，即使 IP 独享，设备指纹和浏览器环境也会被关联。要做矩阵，就按账号数量准备机器，或者至少做到环境隔离。

**优惠码能叠加吗？**
目前的码都是按计费周期或线路类型区分的，没有叠加的依据。一次用一个，选最适合你当前付费方式的那张。
